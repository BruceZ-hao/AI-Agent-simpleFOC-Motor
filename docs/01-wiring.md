# 01 · 接线与电源

## 硬件电气要点（DengFOC-Mini / MP6536 版）

| 项目 | 值 | 对代码的约束 |
| --- | --- | --- |
| VIN / VSP | 5~24V（芯片 5~26V，板厂留余量），12V 最稳 | `V_SUPPLY` 有编译期范围检查，绝不超过 24V |
| 相电流 | **5.5A 峰值**，逐周期内部限流，非持续电流 | 小 QFN 板连续 1~2A 就明显发热，别长时间堵转 |
| PWM 输入 | 3PWM：高 = 上管开，低 = 下管开，内部 10ns 死区 | 正好对应 `BLDCDriver3PWM`，不需要 6PWM / 软件死区 |
| PWM 逻辑高阈值 | 1.6~1.8V | ESP32 的 3.3V GPIO 可直驱，无需电平转换 |
| EN | 板上把 SHDNB（低有效关断）与 STBYB（高有效待机）并到一起 | **EN 必须为 3.3V 才有输出**；若把 EN 硬接 3V3，删掉 driver 构造第 4 个参数 |
| FAULTB | 开漏低有效，过流 / 过温(160°C) / 欠压(≈4.4V) 拉低 | 故障灯亮立刻断电，部分板需重新上电才能恢复 |
| 逻辑电源 | 芯片只有 VSP 一个电源脚 | 板载 VCC 脚需按下述方法判别，别乱灌电 |

## ESP32-S3-DevKitC-1（当前主方案）

| ESP32-S3 | 接往 | 备注 |
| --- | --- | --- |
| GPIO4 | IN1 | 相 A |
| GPIO5 | IN2 | 相 B |
| GPIO6 | IN3 | 相 C |
| GPIO7 | EN | 使能 |
| GPIO8 | AS5600 SDA | S3 默认硬件 I²C，时序最稳 |
| GPIO9 | AS5600 SCL | |
| 3V3 | AS5600 VCC | **只接 3.3V**，别接 5V |
| GND | 驱动板 GND + AS5600 GND | 必须共地 |
| 原生 USB 口 | PC | 给 ESP32 供电 + USB CDC 串口 |

电机三相接驱动板 M1/M2/M3；驱动板 VIN/VM + GND 接外部 12V 电源（**限流 1A**，VIN 端并 470µF）。

**S3 引脚禁区**：`GPIO0/3/45/46`（strapping）、`19/20`（原生 USB D-/D+）、`26~32`（Flash/PSRAM）、`33~37`（部分 WROOM-1 批次 octal PSRAM）、`43/44`（默认 UART0）、`48`（板载 WS2812 RGB）。项目选的 4~9 全部是安全普通 GPIO；S3 有 MCPWM，任意可用 GPIO 都能当 PWM，没有引脚组限制。C3 用的是 LEDC，两者 PWM 后端不同但 `BLDCDriver3PWM` 用法一样。

## ESP32-C3 SuperMini（历史版本）

| ESP32-C3 | 接往 |
| --- | --- |
| GPIO3 / 4 / 5 | IN1 / IN2 / IN3 |
| GPIO6 | EN |
| GPIO7 / GPIO10 | AS5600 SDA / SCL |
| 3V3 / GND | AS5600 VCC / 共地 |

C3 的 `18/19` 是原生 USB D-/D+、`20/21` 是 UART0、`2/8/9` 是 strapping 脚，**不能把 S3 的 4~9 接线照抄到 C3**。C3 版必须开 `USB CDC On Boot = Enabled`，否则 `Serial` 跑 UART0，电脑上什么都看不到。

## 上电前检查顺序

1. **只接 VIN + GND，其余线全不接**，万用表量驱动板 VCC 对 GND：
   - 已有 3.3V → 板载 LDO 输出，**别再灌电**，可顺手给 AS5600 供电；
   - 0V → 输入 / 上拉参考，接 ESP32 的 3V3。
   判别错了会倒灌烧 LDO。
2. 确认三相线、共地线、AS5600 四根线、EN 线全部接牢；FAULT 灯可不接。
3. 12V 电源先设限流 1A，再上电；ESP32 用原生 USB 口单独供电。
4. AS5600 正对轴端径向充磁磁铁，**气隙 1~3mm、尽量同心**；I²C 地址 `0x36`（AS5600L 是 `0x40`）。
5. 让电机轴**空转**（没装旋钮 / 没用手捏住）再烧录或复位，因为 `initFOC()` 会正反微转做对齐。

## 现象速查

| 现象 | 优先排查 |
| --- | --- |
| 串口 `AS5600 not found at 0x36` | SDA/SCL 接反或虚焊、VCC 未供 3.3V、地址是 0x40 的 AS5600L |
| 三相无输出、`Ua/Ub/Uc` 全是 6V 左右（50% 占空） | EN 没拉高、VIN 没上电、共地缺失、`V_LIMIT` 太小 |
| FAULT 灯亮 / 电机发热 | 过流、欠压或过温；立刻断电查相线短路与 `voltage_limit / 相阻` |
| 手转一圈角度不是 0~6.28 线性 | 磁铁装反 / 气隙过大 / 磁铁不是径向充磁 / 编码器板没与轴同心 |
