# 04 · 机械件：台架与整机外壳

两套方案互相独立，**二选一**即可。所有 STL 都做过水密自检（未配对边 / 边界边 / 法线异常均为 0），可直接切片。

## 方案对比

| | `MountBracket/` 开放式台架 | `Enclosure/` 整机外壳 |
| --- | --- | --- |
| 结构 | 三层板 + 4 根 M3 长螺杆 | 圆角底盒 + 顶盖 + 滚花旋钮 |
| 生成方式 | 纯 Python 零依赖，自写扫描线三角化输出 binary STL | Blender 5.3 无头 `bpy` 参数化建模（Boolean / Bevel） |
| 优点 | 敞开、好调线、AS5600 气隙用螺母精调、无需外壳装配 | 一体成型、好看、板卡与线束都有位置、带散热与 USB 开口 |
| 适合 | 调试阶段、要频繁改接线 | 定型后做成品触觉旋钮 |

## 方案 A：开放式台架

`MountBracket/stl/` 五个 STL：

| 文件 | 尺寸 / 作用 |
| --- | --- |
| `01_base_plate.stl` | 130×85×10 底板，夹持无安装孔的 DevKitC-1 / DengFOCmini，四角垫台给板底排针让位 |
| `02_motor_plate.stl` | 130×85×4 电机顶板，径向长槽适配不同孔距的电机底座 |
| `03_sensor_plate.stl` | 130×85×4 AS5600 托板，芯片朝下安装 |
| `04_post_lower.stl` / `05_post_upper.stl` | 各 4 根打印立柱（下段 30.0 / 上段 28.1mm），也可直接用 4 根 M3 长螺杆 |

装配层高（报告里的建议值）：底板 0~4mm → 板卡垫台顶 7mm → 电机顶板底 34mm（电子层净空 30mm）→ 托板下表面 66.1mm，AS5600 芯片底面 63.5mm，**对磁铁顶面 62mm 形成 1.5mm 气隙**（目标 0.5~3mm）。气隙靠 M3 螺母微调，这是台架方案最大的优势。

五金 BOM：M3 长螺杆 ≥78mm ×4 + M3 螺母 ×16 + 垫片 ×8；M3×8 ×4（电机→顶板）；M2×10 ×4 + 螺母 ×4（AS5600 板→托板）；M3×10 ×4（底板固定到桌面，可选）；热熔胶/双面胶少许固定无孔板卡。

改尺寸：编辑 `MountBracket/bracket.py` 顶部参数区，双击 `regen.bat`（会同时重出 STL、`assembly.svg`、`plates_preview.svg`、`build_report.txt`，并做网格自检）。注意报告末尾列出的**参数联动约束**，改一个高度往往要一起改立柱长度、螺杆长度与气隙。

## 方案 B：整机外壳（Blender）

尺寸依据两张实物照片 + 标准板卡尺寸估算：黑色圆柱电机、顶部白色圆盘、底部编码器板、4 根向下尼龙支撑柱、底部线束、ESP32-S3 63×25.5mm（无安装孔）。

| 文件 | 说明 |
| --- | --- |
| `stl/01_lower_case.stl` | 110×76×36 圆角底盒，壁厚 2.4 / 底厚 2.4 / R6；内腔、板卡槽、四角 M3 螺柱、-X 侧 USB-C 开口 12×5、+X 侧 Ø8 出线孔、两侧各 15 条散热格栅、底面 4 个 Ø8 脚垫凹坑 |
| `stl/02_top_cover.stl` | 110×76×3 + 2mm 定位唇边；中央 Ø42 电机沉台、Ø12 中心让位孔、**4 条 45° 径向长槽**（宽 6、半径 12~19，兼容对角孔距 24~38mm 的 4 根支撑柱）、12 个散热孔、BOOT/RESET 针孔、四角沉头螺钉孔 |
| `stl/03_knob.stl` | Ø37.95×13，28 条滚花、Ø5 轴孔、M3 紧定横孔、顶面指位浅碟（也可直接用原装白色转盘） |

电子层内净高 33.6mm；电机装在顶盖上方，散热好、装配简单；总高（含电机与白色转盘、不含旋钮）约 65.6mm。

五金 BOM：M3×12 沉头螺钉 ×4（顶盖→底盒螺柱，自攻进 Ø2.6 孔）、M3 螺母 + Ø10 垫片 ×4（锁电机支撑柱；若柱内是 M3 螺纹改用 M3×10）、Ø8 橡胶脚垫 ×4、热熔胶 + 扎带 ×2、USB-C 数据线 ×1、12V 电源线 ×1。

复现：

```
双击 Enclosure/regen.bat
# 等价于：blender --background --factory-startup --python enclosure.py
python verify_stl.py     # 独立复验 STL 头部三角数、退化面、边配对与法线
```

产物：`Enclosure.blend`（含电机 / 编码器 / 板卡参考体）、3 个 STL、3 张 EEVEE 渲染图（`render/01_assembled.png` 装配 / `02_exploded.png` 爆炸 / `03_interior.png` 内部）、`build_report.txt`。生成器约 70s；无头渲染在集显上会回退但仍能出图。

## 打印前必须实测的假设尺寸

- 电机本体 Ø28×22、白色转盘 Ø34×3、编码器板 Ø30、轴径 Ø5
- 4 根支撑柱 Ø5.5、长 9、分布半径 14（照片估算）；对角孔距 24~38mm
- ESP32-S3 USB-C 端中心高度 z=8.6；BOOT/RESET 针孔位置按常见 DevKitC-1 估计
- 板卡尺寸 63×25.5 / 26×21，两块板都**没有安装孔**，靠垫台 + L 形挡边限位

实测后改 `Enclosure/enclosure.py` 顶部的 `P` 字典（尺寸集中在这里），再跑 `regen.bat`。台架同理改 `bracket.py` 参数区。

## 打印建议

- 材料 PLA / PETG，层高 0.2mm，壁厚 ≥1.2mm（底盒已按 2.4mm 设计），填充 20~30%
- 底盒：底面向下平放，USB-C 开口与散热格栅一般无需支撑（格栅是侧壁竖条）
- 顶盖：平面朝下，沉台与长槽朝上；沉头螺钉孔建议加 0.2mm 余量
- 旋钮：顶面朝上，滚花细节用 0.4mm 喷嘴即可；Ø5 轴孔按实际轴径加 0.1~0.2mm 间隙，M3 紧定横孔可打印后攻一下
- STL 自检里底盒有 2 个零面积三角形，但边配对完整，切片器可忽略
