# 04 · 机械件：台架、整机外壳与独立电机小方板

三套机械方案互相独立，**按需选一套打印**即可。所有 STL 都做过水密自检（未配对边 / 边界边 / 法线异常均为 0），可直接切片。

其中 `Enclosure/stl/05_standalone_motor_plate.stl` 是**完全脱离外壳的一块小方板**：只要固定电机、不想做整机外壳，只打印这一块（约 60×60×5mm）即可。

## 方案对比

| | `MountBracket/` 开放式台架 | `Enclosure/` 整机外壳（01~04） | `Enclosure/` 独立小方板（05） |
| --- | --- | --- | --- |
| 结构 | 三层板 + 4 根 M3 长螺杆 | 圆角底盒 + 顶盖 / 电机锁板（二选一）+ 滚花旋钮 | 单块 60×60×5 平板 |
| 生成方式 | 纯 Python 零依赖，自写扫描线三角化输出 binary STL | Blender 5.3 无头 `bpy` 参数化建模（精确圆角棱柱 + Boolean） | 同一个 `enclosure.py`，独立参数组 `mini_*` |
| 优点 | 敞开、好调线、AS5600 气隙用螺母精调、无需外壳装配 | 一体成型、好看、三块板平放 + 线束/开关都有位置、带散热与 USB 开口 | 最省料最快、两面全平免支撑、不依赖外壳、位置随意 |
| 适合 | 调试阶段、要频繁改接线 | 定型后做成品触觉旋钮 | 只固定电机 / 台架试验 / 临时固定 |

## 方案 A：开放式台架

`MountBracket/stl/` 五个 STL：

| 文件 | 尺寸 / 作用 |
| --- | --- |
| `01_base_plate.stl` | 130×85×10 底板，夹持无安装孔的 DevKitC-1 / DengFOCmini，四角垫台给板底排针让位 |
| `02_motor_plate.stl` | 130×85×4 电机顶板，径向长槽适配不同孔距的电机底座 |
| `03_sensor_plate.stl` | 130×85×4 AS5600 托板，芯片朝下安装 |
| `04_post_lower.stl` / `05_post_upper.stl` | 各 4 根打印立柱（下段 30.0 / 上段 28.1mm），也可直接用 4 根 M3 长螺杆 |

装配层高（报告里的建议值）：底板 0~4mm → 板卡垫台顶 7mm → 电机顶板底 34mm（电子层净空 30mm）→ 托板下表面 66.1mm，AS5600 芯片底面 63.5mm，**对磁铁顶面 62mm 形成 1.5mm 气隙**（目标 0.5~3mm）。气隙靠 M3 螺母微调，这是台架方案最大的优势。

五金 BOM：M3 长螺杆 ≥78mm ×4 + M3 螺母 ×16 + 垫片 ×8；M3×8 ×4（电机→顶板）；M2×10 ×4 + 螺母 ×4（AS5600 板→托板）；M3×10 ×4（底板固定到桌面，可选）；热熔胶/双面胶少许固定无孔板卡。

改尺寸：编辑 `MountBracket/bracket.py` 顶部参数区，双击 `regen.bat`（会同时重出 STL、`assembly.svg`、`plates_preview.svg`、`build_report.txt`，并做网格自检）。注意报告末尾列出的**参数联动约束**，改一个高度往往要一起改立柱长度、螺杆长度与气隙。

## 方案 B：整机外壳（Blender）

尺寸依据两张实物照片 + 标准板卡尺寸估算：黑色圆柱电机、顶部白色圆盘、底部编码器板、4 根向下尼龙支撑柱、底部线束、ESP32-S3 63×25.5mm（无安装孔）。

**当前版本的板卡安装方式**：ESP32-S3、DengFOC-Mini、电源模块三块板的**排针都朝下**，所以底盒内腔改成**完整平底**——不做垫台、挡边、板卡槽，三块板直接堆放在壳内，位置完全自由（STL 里除了四角螺柱，底面没有任何凸起）。板底排针约 2.5mm 自然把板撑起；需要更高/防滑就自行贴泡棉或尼龙脚垫。

### 顶盖 / 底盒结合逻辑（已修正）

早期版本用 `BEVEL` 给整个盒子倒圆角，3mm 薄顶盖的 6mm 圆角宽度被 clamp 成上下斜切：底盒盒口外轮廓缩到 104.2×70.2，比内腔开口 105.2×71.2 还小，侧壁在 z=36 处被切穿；顶盖底面变成「中间鼓、上下缩」的透镜形，没有可贴合的平面。唇边又是一整块 104.4×70.4 的实心板，正好压在四角螺柱（顶面 z=36）上，**顶盖物理上盖不下去**。

现在各配合面按同一逻辑设计：

| 部位 | 几何 | 作用 |
| --- | --- | --- |
| 底盒侧壁 | 精确 R6 圆角棱柱，垂直一直到 z=36 | 盒口留出 2.4mm 宽的**平齐环形口沿** |
| 四角螺柱 | Ø6.2，顶面与口沿共面 z=36 | 和口沿共同承托顶盖，兼作 M3 自攻孔 |
| 顶盖底面 | z=36 完整平面，XY 轮廓与底盒完全相同 | 整面压合、侧面齐平、零缝 |
| 定位唇边 | 4 条直条，宽 2 / 插入 2mm，外边界 X±52.2 / Y±35.2，单边间隙 0.4 | 只管 XY 定位；两端止于螺柱避让半径 3.4，四角完全空出 |
| 锁紧 | 4×M3×12 沉头螺钉，经 Ø3.4 过孔拧进螺柱 Ø2.6 孔 | 把顶盖压紧在口沿上 |

`render/04_fit.png` 是顶盖抬高 22mm 的正交结合细节图，能看到平齐口沿、内腔与顶盖同宽齐平；`render/05_lip.png` 从下方仰视顶盖底面，橙色高亮的四条直唇边与四角空位一目了然（橙色只是渲染标注色，打印件仍是单色）。`verify_fit.py` 把这些配合关系做成了自动检查（口沿存在、外轮廓一致、唇边不越界、与螺柱不干涉、共面，以及锁板孔位 / 沉腔 / 安装孔），`regen.bat` 每次重生成都会跑。

### 电机锁板：把 4 根铜柱真正锁死

照片里电机底部有 **4 根铜柱**（连接编码器板与安装板），临时用手头的白板钻孔、柱端拧螺母只是"带住"，电机仍会随旋钮扭动窜位，白板本身也没有和外壳固定。

`02_top_cover.stl` 的 4 条 45° 径向长槽（半径 12~19、宽 6）只是**让位**，兼容不同孔距但会滑动。要真正固定，改打印 `04_motor_lock_plate.stl`——它与顶盖**共用同一装配位，二选一**：

| 项目 | 数值 / 做法 |
| --- | --- |
| 4 个铜柱孔 | Ø3.4 通孔，中心在半径 `lock_post_r`、角度 45/135/225/315°；默认 R=14 → 坐标 (±9.90, ±9.90)，相邻孔距 19.80 / 对角 28.00mm |
| 螺母沉腔 | 板底面对边 5.8、深 2.6 的**正六角**凹腔，M3 六角螺母（对边 5.5）嵌进去不能自转，铜柱从上穿过后单手拧紧即可 |
| 板厚 | 5.0mm，沉腔上方仍留 2.4mm 承力；比 3mm 顶盖更抗电机反扭矩 |
| 与底盒的连接 | 四条同样的定位唇边插入内腔，底面 z=36 压在口沿与四角螺柱顶面上，4×M3×12 沉头螺钉锁死 |
| 若铜柱是内螺纹 standoff | 孔不用改，从板底用 M3×10 螺钉穿过沉腔拧进铜柱，沉腔同样容纳螺钉头 |

**孔距实测（照片无法精确量，默认 R=14 是按现有参考体估算）**：量对角两根铜柱的中心距 `L` → `lock_post_r = L/2`；或量相邻两根中心距 `S` → `lock_post_r = S/1.414`。若柱子沿 X/Y 轴而不是 45° 对角分布，把 `lock_post_angles` 改成 `(0, 90, 180, 270)`。一时量不准就先把 `lock_hole_mode` 设成 `"slot"`（长槽，免实测但可滑动），装好后量准再切回 `"round"` 重打一块。铜柱不是 M3 就同步改 `lock_hole_d / lock_nut_af`。

`render/06_lock_plate.png` 用爆炸视图展示了「电机 + 4 根铜柱 → 锁板 → 4 个六角螺母」的锁止关系；`render/07_lock_underside.png` 从板底仰视，橙色高亮的 4 个六角沉腔和嵌在里面的螺母一目了然（橙色只是渲染标注色，打印件仍是单色）。

### 独立电机小方板（05）：只固定电机，不做外壳

如果目标是「把电机锁住」而不是做整机，只打印这一块板就够了。它**不装进 110×76 底盒**，没有外壳轮廓、没有唇边、没有沉头螺钉孔、没有电机沉台——就是一块两面全平的小方板，最容易打印。

| 项目 | 数值 / 做法 |
| --- | --- |
| 外形 | `mini_w × mini_d × mini_t` 默认 **60×60×5mm**，圆角 `mini_r=5`；STL 以板底面 z=0 为原点 |
| 4 个铜柱孔 | **与 04 锁板逐字共用** `lock_post_r / lock_hole_d / lock_post_angles / lock_hole_mode`：实测一次孔距，两块板一起对准 |
| 螺母沉腔 | 同样在板底，正六角对边 5.8 / 深 2.6，M3 螺母嵌进去防转，铜柱从上方穿过拧紧 |
| 中心 / 线束 | 中心 Ø12 让位孔（编码器磁铁 / 轴端），Ø9 线束过孔在 (0, -20) |
| 四角安装 | 4 个 Ø4.2 通孔在 (±25, ±25)，**正好落在 R5 圆角圆心上**，四周最小壁厚 2.90mm；M4 螺钉 + 螺母把板锁到桌面 / 支架 / 铝型材 |

**参数联动**：`mini_w / mini_d / mini_r` 改了，`mini_mount_x / mini_mount_y` 要同步改成 `边长/2 - mini_r`，让安装孔始终落在圆角圆心，否则会切穿圆角边。`verify_fit.py` 会自动检查这个壁厚（要求 >0.8mm）。

**量测**：孔距量法与 04 锁板完全相同（对角距 `L` → `lock_post_r=L/2`）；`lock_hole_mode="slot"` 同样适用于这块板，免实测先用长槽装上。铜柱若是内螺纹 standoff，从板底用 M3×10 螺钉穿过六角腔拧进铜柱。

`render/08_standalone_plate.png` 是纯板件顶面俯视，4 个铜柱孔、4 个安装孔、中心让位孔与线束孔一目了然；`render/09_standalone_underside.png` 从板底仰视，橙色高亮 4 个六角沉腔，四角安装孔也清晰可见。装配顺序（铜柱 → 板 → 螺母）与 04 锁板完全相同，可对照 `render/06_lock_plate.png` 的爆炸示意。

### 三块板的建议布局（内腔 105.2×71.2mm）

| 板卡 | 标称尺寸 | 中心 (X,Y) | 实际占位 |
| --- | --- | --- | --- |
| ESP32-S3-DevKitC-1 | 63×25.5 | (-18, -12) | X -49.5~13.5 / Y -24.8~0.8，USB-C 对准 -X 侧壁开口 |
| DengFOC-Mini | 26×21 | (-28, 15) | X -41~-15 / Y 4.5~25.5 |
| 电源模块（5×3.5cm） | 50×35 | (32, 0) | 竖放：X 14.5~49.5 / Y -25~25，靠近 +X 出线孔与开关 |

三者互不重叠，也不碰四角螺柱 (±49, ±32)；这只是渲染参考体的摆放，**STL 里没有任何限位结构**，实际随便挪。电源模块放在 +X 侧是为了离 12V 进线和开关近。

### 侧边电源开关口

+X 侧壁、y=-18、z=16 处开孔，与 Ø8 出线孔（y=12）错开 30mm，串在 12V 正极上做总开关：

- 默认 `sw_shape="round"` → **Ø6.5 圆孔**，适配 MTS-102 类小型拨动开关；
- 想用船型开关：把 `sw_shape` 改成 `"rect"` → **19×13mm 矩形孔**（沿侧壁 Y 宽 × 竖直 Z 高），并按实物核对 `sw_rect_w / sw_rect_h`；
- 完全不需要：`sw_shape="none"`。

电子层内净高 33.6mm；电机装在顶盖上方，散热好、装配简单；总高（含电机与白色转盘、不含旋钮）约 65.6mm。

五金 BOM（整机外壳）：电源模块 50×35 ×1、拨动/船型开关 ×1、泡棉双面胶或尼龙脚垫 2~3mm 若干（可选）、M3×12 沉头螺钉 ×4（顶盖 / 锁板→底盒螺柱，自攻进 Ø2.6 孔）、**M3 六角螺母 ×4**（锁板方案：嵌进板底六角沉腔；若铜柱是内螺纹 standoff 改用 M3×10 螺钉）、M3 螺母 + Ø10 垫片 ×4（顶盖长槽方案，仅让位不锁死）、Ø8 橡胶脚垫 ×4、热熔胶 + 扎带 ×2、USB-C 数据线 ×1、12V 电源线 ×1。

五金 BOM（只用 05 独立板）：M3 六角螺母 ×4（板底沉腔）、M4×12 螺钉 + 螺母 ×4（四角 Ø4.2 孔固定到平台，也可换 M3 + 垫片）、扎带若干固定线束。**不需要外壳的任何五金。**

## 打印前必须实测的假设尺寸

- 电机本体 Ø28×22、白色转盘 Ø34×3、编码器板 Ø30、轴径 Ø5
- 4 根铜柱 Ø5.5、长 9、分布半径 14（照片估算）；顶盖长槽兼容对角孔距 24~38mm
- **★ 锁板 / 独立板 4 孔孔距**：默认 `lock_post_r=14`（相邻 19.8 / 对角 28.0mm）纯属估算，必须量实物对角孔距 L 并令 `lock_post_r=L/2`，否则孔对不上铜柱；量不准先用 `lock_hole_mode="slot"`（两块板共用同一参数）
- **05 独立板 60×60×5 是自定义尺寸，不是实物量测值**：按你的平台自行改 `mini_w / mini_d`；改完同步 `mini_mount_x / mini_mount_y = 边长/2 - mini_r`
- ESP32-S3 USB-C 端中心高度 z=8.6；BOOT/RESET 针孔位置按常见 DevKitC-1 估计
- 板卡尺寸 63×25.5 / 26×21 / **50×35**，三块板都**没有安装孔**、排针朝下
- 「5×3.5」按 **5cm×3.5cm = 50×35mm** 理解；若单位不同，改 `P` 里的 `psu_w / psu_d`，横放就把 `psu_rotate` 设为 `False`
- 开关口默认 Ø6.5；打印前拿实物开关比一下开孔（船型开关常见 19×13 或 13×19）

实测后改 `Enclosure/enclosure.py` 顶部的 `P` 字典（尺寸集中在这里），再跑 `regen.bat`。台架同理改 `bracket.py` 参数区。

## 打印建议

- 材料 PLA / PETG，层高 0.2mm，壁厚 ≥1.2mm（底盒已按 2.4mm 设计），填充 20~30%
- 底盒：底面向下平放，USB-C 开口、Ø8 出线孔、开关口与散热格栅一般无需支撑（格栅是侧壁竖条）
- 开关口若用船型开关，矩形孔四角建议加 0.3mm 圆角余量，避免卡扣装不进
- 顶盖：平面朝下，沉台与长槽朝上；沉头螺钉孔建议加 0.2mm 余量
- 04 锁板：**六角沉腔面（底面）朝下**，沉腔上方是跨度 5.8mm 的短桥，PLA 直接桥接免支撑；Ø3.4 过孔打印后可拿 3.5mm 钻头轻扩，M3 螺母先按进六角腔再拧铜柱
- **05 独立板两面都是平面，随便哪面朝下都能打**，是所有零件里最容易打印的一个；六角沉腔面朝下时同样是 5.8mm 短桥，免支撑
- 锁板与顶盖**只打印一块**，别两块都打；05 独立板与外壳没有任何装配关系，单独打印一块即可
- 05 独立板装配：螺母按进板底沉腔 → 电机 4 根铜柱从板顶穿过 Ø3.4 孔拧紧 → 线束从 Ø9 孔引出 → 四角 Ø4.2 孔用 M4 螺钉锁到平台
- 顶盖下表面的四条唇边会先接触平台、主体下方留 2mm 空隙，切片软件会加一层很薄的支撑，很容易拆；想完全免支撑就把 `P["lip_h"]` 调到 1.0（定位深度变浅）或把顶面朝下（Ø42 沉台处需要桥接）
- 试装时先不拧螺钉，顶盖应能整面落到底、四周齐平无缝；若顶手，检查螺柱顶面毛刺或唇边是否被切出了大象脚
- 旋钮：顶面朝上，滚花细节用 0.4mm 喷嘴即可；Ø5 轴孔按实际轴径加 0.1~0.2mm 间隙，M3 紧定横孔可打印后攻一下
- STL 自检里底盒有 2 个零面积三角形，但边配对完整，切片器可忽略
