【04 电机锁板 —— 把 4 根铜柱真正锁死】（本次新增）
  * 与 02_top_cover.stl 二选一打印：两者外形 / 唇边 / 四角螺钉孔完全相同，装在同一位置。
    02 是 4 条径向长槽（只让位，电机仍能沿槽窜动）；04 是 4 个精确孔 + 螺母沉腔（锁死）。
  板厚 5.0 mm（六角沉腔深 2.6 后仍留 2.4 mm 承力），底面 z=36.0 压在口沿与螺柱顶面上。
  4 个 Ø3.4 通孔，中心在半径 R=14.0 mm、角度 45/135/225/315°；
  即坐标 (±9.90, ±9.90)，相邻孔距 19.80 mm、对角孔距 28.00 mm。
  每个孔底面有对边 5.8、深 2.6 的六角沉腔：M3 螺母嵌进去不能自转，铜柱从上往下穿过后单手拧即可锁紧，电机不会再随旋钮扭动而窜位。
  若铜柱是内螺纹铜柱（standoff）而不是外螺纹螺杆：不改孔，从板底用 M3x10 螺钉
  穿过沉腔拧进铜柱即可，沉腔同样容纳螺钉头。
  ★ 孔距实测方法（照片无法精确定尺寸，默认 R=14.0 是按现有参考体估算）：
      量对角两根铜柱中心距 L -> lock_post_r = L / 2
      或量相邻两根中心距 S   -> lock_post_r = S / 1.414
      若柱子沿 X/Y 轴而不是 45° 对角，把 lock_post_angles 改成 (0, 90, 180, 270)。
      一时量不准就先把 lock_hole_mode 设成 'slot' 装上，量准后再切回 'round' 重打一块。
  装配示意见 render/06_lock_plate.png（爆炸展示铜柱 / 锁板 / 六角螺母）；
  板底 4 个六角沉腔见 render/07_lock_underside.png（橙色为渲染标注色，打印件单色）。

【装配顺序】
  1. 底盒朝上，把电源模块、DengFOC-Mini、ESP32-S3 排针朝下直接放进去（无卡槽，位置自由），
     让 ESP32 的 USB-C 对准 -X 侧壁开口；需要防滑就垫 2~3mm 泡棉。
  2. 开关装进 +X 侧壁开孔；12V 电源线从 Ø8 出线孔穿入，经开关到电源模块，
     模块输出再分给驱动板 VIN 与 ESP32；三相线 + 编码器线从顶盖 Ø9 过孔穿入。
  3. 【二选一】用 02 顶盖：4 根铜柱对准长槽插入，从盒内侧用 M3 螺母 + Ø10 垫片带紧（可滑动）。
     用 04 锁板：先把 M3 六角螺母按进板底 4 个六角沉腔，铜柱从上方穿过 4 个 Ø3.4 孔
     拧进螺母并锁紧；电机与锁板成为一体，再把锁板盖到底盒口沿上。
  4. 盖上顶盖 / 锁板：四条唇边对准内腔插入，底面压平在口沿与四个螺柱顶面上，四角拧入 M3x12 沉头螺钉。
     先不拧死、试合一次：顶盖应能整面落到底、四周无缝，若有顶手就检查螺柱顶面是否有毛刺或唇边是否被切片机加了支撑/大象脚。
  5. 白色转盘即现成旋钮；若要更大握持感，套上 03_knob.stl 并用 M3 紧定螺钉固定。

【与固件的配合 / 安全】
  - 上电 initFOC() 会让电机正反各走一个电周期，务必让旋钮自由、别用手捏住。
  - 校准需 12V 与三相线都接好；失败会打印 Failed to notice movement 并卡住，按 RESET 重来。
  - 手扭住不放时电机持续堵转输出，MP6536 会发热，不用时发 T0 并断 12V。
  - 重烧固件前关闭上位机 / IDE 串口监视器，释放串口。
  - 本外壳与之前的 MountBracket 三板支架是两套独立方案，二选一即可。
